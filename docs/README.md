# docs/

| Folder / file | Contents |
|---|---|
| `research/` | Project brief, research questions, existing systems, datasets, algorithm choices, course-material mapping |
| `decisions/` | Architecture Decision Records (ADRs). One decision per file, numbered, never deleted (superseded instead) |
| `model_cards/` | One card per model that reaches `production`: data, metrics, per-group slices, limits |
| `dataset_cards/` | One card per dataset source: provenance, licence, composition, known gaps |
| `runbooks/` | Operational procedures: incidents, rollback, key rotation, erasure |
| `gloss_conventions.md` | How KSL glosses are written (SSOT for annotators and `lexicon.glosses`) |
| `bias_impact_statement.md` | Brookings-style statement, updated every major release |
| `dpia.md` | Data protection impact assessment (Kenya Data Protection Act, 2019) |
| `glossary.md` | Terms used across the project |
