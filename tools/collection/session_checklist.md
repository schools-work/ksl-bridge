# Recording session checklist

- [ ] Ethics approval number written on the session sheet
- [ ] KSL interpreter present; consent video shown; written consent signed; `privacy.consents` row created
- [ ] `dataset.recording_sessions` row created (device model and tier, lighting, background, posture, distance)
- [ ] Phone on a tripod at chest height, front camera, 720p, 30 fps, **unmirrored**
- [ ] Test clip recorded and landmark visibility checked (both hands visible ≥ 95% of frames)
- [ ] Script order randomised per signer
- [ ] Breaks every 20 minutes; water available
- [ ] Payment recorded
- [ ] Uploads verified (checksums) before deleting anything from the phone
